# Практический TypeScript

[Открыть тренинг](https://infame.github.io/practical-typescript-refresher/ru/) · [English](README.md) · [Español](README.es.md)

Практическое повторение для разработчиков, которые умеют программировать и хотят вернуться к TypeScript. **Выбрать тему → повторить правило → написать код → сравнить решение.** Все 14 глав и общая практика доступны на английском, русском и испанском. Канонический язык — английский.

## Как пользоваться

- Выберите тему или готовый маршрут: возвращение к TypeScript или подготовка к практическому backend-интервью. Практика входит в оба маршрута между практикумом и пробным интервью.
- Вверху справа выберите область примеров: каталог товаров, аналитика, фоновые задачи или профили. Контракты заданий общие; в примеры подставляются выбранные имена и поля.
- Напишите решение в привычном редакторе, пройдите проверки с ожидаемыми результатами, затем откройте спойлер. Кнопка «Скопировать код» копирует пример; сайт не выполняет вашу реализацию.
- Ищите по объяснениям и коду, включая ответы. Прогресс хранится в браузере и общий для всех языков.

Необязательная самопроверка из 12 вопросов ведёт к объяснениям и официальным справочникам. Она проверяет отдельные правила, а не умение писать код. При уходе со страницы ответы не сохраняются. Регистрация не нужна, аналитики и отправки ответов на сервер нет.

## Темы

Типы, inference, narrowing, generics, поведение JavaScript, коллекции, async, конкурентность, валидация, загрузка данных, отладка и тесты. Десять разборов ошибок компилятора, практикум и пробное интервью помогают перейти от объяснений к коду.

SQL, надёжная доставка, алгоритмические приёмы и инструменты Node разобраны на вводном уровне. Фреймворки, безопасность, system design и специализированные алгоритмы требуют отдельной подготовки. Это повторение, а не обещание пройти любое интервью.

## Локальный запуск

Нужны Node.js 24+ и npm. В каталоге клонированного репозитория:

```sh
npm ci
npm run build
npm start
```

Откройте http://127.0.0.1:4173/ru/. Английская версия — `/`, испанская — `/es/`. Используйте HTTP-сервер, а не прямое открытие HTML-файлов.
