# Практический TypeScript

[Читать курс в браузере](https://infame.github.io/practical-typescript-refresher/)
Курс для разработчика, который умеет программировать, но подзабыл TS. **Объяснение → код → задача → Спойлер.** 14 глав, браузерный просмотр и проверяемые реализации.

## Запуск

Нужны Node.js 24+ и npm:

```sh
npm ci
npm run verify
npm start
```

Открыть http://127.0.0.1:4173. После сборки можно открыть dist/index.html без сервера; общий прогресс между file:// страницами зависит от браузера.

## Как проходить

На стартовой странице два маршрута: восстановить язык после перерыва или подготовиться к практическому интервью. Prev / Next следуют выбранному маршруту. Прогресс сохраняется локально и считает пройденные главы; он не оценивает знания.

Перед Спойлером попробуй ответить вслух, затем напиши решение руками. После разбора реши новую вариацию, иначе проверишь узнавание, а не перенос навыка.

Исходники — lessons/*.md. Рабочие реализации — examples/core.ts и examples/workshop.ts. Независимые задания — benchmarks/TASKS.md. [Аудит](docs/AUDIT.md) и [оценка](docs/EVALUATION.md) описывают, что проверено и чего результаты не доказывают.

## Содержание

1–10: коллекции, runtime JS, практический TS, async, mapLimit, ingestion, базы и события, алгоритмы, review, mock interview.

11–14: восстановление языка, проектирование типов, модули и compiler-настройки, четыре практических задания.

Числа глав сохраняют старые ссылки, а порядок изучения задаётся маршрутом. React, DOM, decorators и сложная разработка библиотек вне основной программы этой редакции.

## Проверки и правки

```sh
npm run verify
npm run eval -- /absolute/path/to/solution.ts
```

Последняя команда выполняет переданный код на компьютере; используйте собственный или проверенный модуль. Правила добавления уроков и проверяемых фрагментов — в CONTRIBUTING.md. Лицензия MIT; attribution зависимостей — THIRD_PARTY_NOTICES.md.
