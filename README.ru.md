# Практический TypeScript

[Открыть русский тренинг](https://infame.github.io/practical-typescript-refresher/ru/) · [English](README.md) · [Español](README.es.md)

Для разработчика, который умеет программировать, но подзабыл TS. **Найти пробел → повторить правило → написать код → проверить решение.** Все 14 глав, диагностика и практика доступны на трёх языках; английский — основной.

На главной — 12 диагностических вопросов. Ошибки и «Не знаю» дают объяснения, главы для повторения и ссылки на MDN / TypeScript / Node. Балл отражает ответы, а не умение написать код. Регистрация не нужна, ответы никуда не отправляются.

Вверху справа выбираются язык и область: каталог товаров, аналитика, фоновые задачи или профили. Правила и три практических задания общие, имена сущностей и поля подставляются в примеры. Выбор сохраняет страницу и маршрут. Поиск индексирует объяснения и код, включая решения, и ведёт к нужному разделу. Прогресс глав сохраняется локально и общий для языков.

Два маршрута: восстановление TS после перерыва и подготовка к практическому backend-интервью. Навигация сверху и снизу следует выбранному маршруту. Тренинг покрывает язык, коллекции, async, валидацию, обработку данных и ошибок. SQL, события, алгоритмы и Node — вводные темы. React/DOM, фреймворки, безопасность, system design, сложная DP и распределённые транзакции требуют отдельной подготовки. Это не обещание пройти любое интервью и не программа конкретного работодателя.

## Запуск и проверка

Нужны Node.js 24+ и npm:

```sh
npm ci
npm run verify
npm start
```

Открыть http://127.0.0.1:4173/ru/. Используйте HTTP-сервер: браузерные модули не рассчитаны на открытие через file://.

Исходники: `lessons/*.md` — русский, `lessons/en/` и `lessons/es/` — переводы; `content/` — общая практика, вопросы и интерфейс. Реализации — `examples/`. После правок выполните `npm run build`.

[Правила вклада](CONTRIBUTING.md) · [Общие задания](docs/DOMAIN-PRACTICE.md) · [Аудит](docs/AUDIT.md) · [Оценка](docs/EVALUATION.md)

Независимые задания — `benchmarks/TASKS.md`; `npm run eval -- /absolute/path/to/solution.ts` выполняет переданный код на компьютере. Используйте собственный или проверенный модуль. Прохождение тестов примерами и эксперимент с LLM не доказывают эффективность обучения людей.
